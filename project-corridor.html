Corridor Scout

Python · React · TypeScript

I built a dashboard comparing recorded remittance costs across ten UK outbound corridors. A five-step Python pipeline downloads, validates, cleans and analyses World Bank data before publishing it to the interface.

The included Q3 2025 data contain 394 amount observations from 197 transparent quotations across five providers. These are historical quotations, not live prices or completed transfers; fee and exchange-rate comparisons are diagnostic, not causal.
